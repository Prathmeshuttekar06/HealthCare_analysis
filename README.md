# Healthcare Analysis

Exploratory healthcare data analysis project covering patient demographics, medical conditions, admissions, length of stay, and billing amounts.

## Contents

- `Data/` - Original and cleaned healthcare datasets in CSV format.
- `Notebook/healthcare_analysis.ipynb` - Analysis notebook with data exploration and visualizations.
- `Visuals/` - Exported charts from the analysis.
- `tableau/HealthCare_dashboard.twb` - Tableau dashboard workbook.

## Analysis Topics

- Patient and admission overview
- Medical condition comparisons
- Billing amount distributions
- Length of stay analysis
- Admission type analysis

## Getting Started

Open `Notebook/healthcare_analysis.ipynb` in Jupyter Notebook or Visual Studio Code, then run the cells using the files in `Data/`.

The Tableau workbook can be opened with Tableau Desktop or Tableau Public.
